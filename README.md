# MyProject2
## Hospital Management System

### Description
This is a console-based Hospital Management System developed in Python using Object-Oriented Programming (OOP).

### Features
- Register Patients
- Search Patients
- Update Patients
- Delete Patients
- Save records to a CSV file

### Classes

#### 1. Person
- Abstract base class
- Stores book name, ID, and age

#### 2. Patient
- Inherits from Person
- Stores the Patient's disease 
- Implements the display_details() method

#### 3. HospitalManagementSystem
- Manages all patient records
- Handles searching, updating, deleting, and file operations

### OOP Concepts Used
- Abstraction
- Inheritance
- Encapsulation
- File Handling
- Exception Handling

### How to Run

```bash
python Hospital_Management_System.py
```
